# Relay

Relayは、災害などでインターネットや携帯回線が不安定な状況でも、救助情報をできるだけ届け続けるための実験的な通信プロジェクトです。

Android端末で作成した救助情報を暗号化し、利用可能な経路を使ってPC Gatewayへ中継します。

## 主な構成

- Androidアプリ
- 端末間・LAN経由の中継
- PC Gateway
- HTTPS Broker
- 受信確認用の署名付きReceipt

## 注意

Relayは開発・検証段階のプロジェクトです。
119、消防、警察、自治体などの公式な緊急通信手段を置き換えるものではありません。

公開版には、特定地域向けの設定、個人情報を含む資料、スクリーンショット、過去のコミット履歴は含めていません。
